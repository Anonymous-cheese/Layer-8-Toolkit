# Bundled IANA port registry

`iana-service-names-port-numbers.csv` is an unmodified snapshot downloaded on
2026-10-20 from
https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.csv .
The IANA registry page listed its last update as 2026-10-15.

SHA-256: `B6AFEEFDC6B2C616F9A515D57819A558EBE33250B59B2700B3AFC4A4BA1923F2`

IANA and IETF make protocol registry data available under CC0 1.0:
https://www.iana.org/help/licensing-terms . The app adds a small, separately
identified set of common-use search aliases; those are not part of the official
registry. No runtime network request is used to load or search this snapshot.
